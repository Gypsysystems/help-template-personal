Advanced Search

Advanced Search enables you to seamlessly search, combine, and analyze data from different data sets. It provides a practical and powerful means to investigate and compare data sets effectively.

Using Advanced Search, you can:

  • Search for data using the specific search types.
  • Create multiple and sequential search steps in which each search step can be independent or a search result from the previous step.
  • Search for data simultaneously for all the search steps.
  • Combine data sets to narrow down your search results.
