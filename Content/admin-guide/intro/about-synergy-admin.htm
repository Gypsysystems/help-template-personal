About Synergy

Synergy is an integrated AI data management platform designed to handle data-related tasks, including ETL (Extract, Transform, Load) and AI transformations, which enables you to apply complex business logic to your data. Additionally, it enables users across your organization to search, access, and analyze the same data and collaborate as a team.

Synergy includes a mass profiling framework that enables deeper analysis than a table-only view by consolidating entity information (for example, employees, customers, or digital identities) into unified Profiles and connecting those Profiles using identifiers, relationships, and involvement types.

Synergy is designed to help organizations manage, integrate, and monitor various data sources. It streamlines data handling and provides tools for configuring system settings, monitoring system health, and controlling user access.

As an Administrator, you can:

  • Connect, manage, and perform operations directly in data sources to ensure smooth data flow.
  • Set up ETL and code executors to support data processing and execution workflows.
  • Monitor system health through dashboards that show logs, tasks, and notifications.
  • Configure system-wide settings, such as date formats and number formats, which apply across the platform.
  • Customize graph and map settings for better data visualization.
  • Set API limits to manage system performance.
  • Configure entities by defining identifiers, profiles, and relations.
  • Configure LLM models and LLM agents to support AI-assisted platform capabilities.
  • Manage notification destinations for system alerts and communication workflows.

The platform offers flexibility in managing data while maintaining system stability.

Note: It is recommended that you avoid changing critical settings once the system is set up.

Synergy Admin Components

The following are the core components of Synergy:

System Dashboard

A System Dashboard is an information aggregation and visualization tool that enables you to explore and analyze different kinds of data. Dashboards enable you to create visualizations using a schema and interact with them. These visualizations are charts, data, and maps.

The System Dashboard allows you to monitor the platform's health and activity. It displays data from system-level schemas, such as query logs, audit logs, tasks, and notifications. You can create dashboard visualizations to track performance, errors, and system usage in real time. This helps you ensure that all operations are running smoothly and securely.

Settings

The Settings component enables you to define system-wide configurations that affect how data is displayed and processed across the platform. You can set default date ranges, date-time formats, and number formats. You can also select rendering engines for graphs, configure map defaults (such as coordinates and base map type), and set API timeouts and search limits.

Additional configurations include enabling face search, setting profile image URLs, defining company branding, and defining workspaces. These settings ensure consistency in how users experience and interact with data.

Entity Configuration

The Entity Configuration component enables you to define how entities (such as people, organizations, or objects) are structured and related within the platform. You can configure Identifier Types, Profile Types, Relation Types, and Profile Involvement Types. These configurations help the system interpret and connect data records.

Example: Identifiers define unique keys for Profiles, and relations define how the entities are linked.

Note: Configuring entities is critical for setting up entity models and should be managed carefully to avoid inconsistencies in data relationships.

The Entity Configuration component enables you to create and configure the following types of entities:

  • Identifier: Creates unique identifiers that link data across multiple entities. Identifiers are defined by specific names, icons, colors, and formats to ensure consistent and accurate cross-entity data connections.
  • Profile: Creates a consolidated data entity by associating identifiers, attributes, and other entities. Profiles integrate and organize data, providing a unified view for processing.
  • Relation: Creates connections between Profiles by defining their relationships, including the roles and interactions between entities. This entity type specifies how Profiles are linked.
  • Profile Involvement: Determines how individual Profiles behave in the application by defining key attributes such as role, engagement parameters, color coding, and severity level to indicate their status or priority.

Data Management

The Data Management component enables you to organize and analyze various data sources associated with a workspace.

The Data Management component enables administrators to connect, configure, and manage data sources for the workspace.

In the Data Management component, you can:

  • Add data sources.
  • Create and manage schemas.
  • Synchronize data sources with the workspace.
  • Manage analytical schemas within schemas.
  • View and manage database tables and columns.

Synergy supports data sources stored in various databases and storage systems, such as ClickHouse, S3, Minio, and Postgres.

Data Catalog

The Data Catalog provides a searchable inventory of all data assets within the workspace. It helps users explore available schemas, tables, columns, and data sources. You can view metadata, such as descriptions and types, to better understand the data structure and contents. Data Catalog provides organization-wide visibility into available data and its structure, improving data discovery and governance.

Query Log

The Query Log component enables you to view a history of all queries executed within the platform. It includes detailed records such as query content, execution time, user, status, and result size. This log helps monitor system usage, identify slow or failed queries, and audit user activities. The information available in the Query Log component is useful for performance tuning, troubleshooting, and ensuring query compliance across workspaces.

Workers

The Workers component displays the backend processing units that execute data tasks, such as queries, rule evaluations, and data pipelines. It acts as a system-level task manager, allowing you to see the number of active and pending workers, monitor performance, and detect issues in data processing. Each Worker in Synergy processes data or queries in isolation, helping the platform scale and manage load efficiently.

Executors

The Executors component automates task execution in a data pipeline by monitoring specific events, such as the arrival of new data files, and triggering the appropriate tasks to maintain a smooth data flow. It enables you to register the existing executors already deployed in your environment.

You can create ETL Executors or modify the existing code executors.

Executors provide the execution environments that Synergy uses to run data processing tasks and custom code. The Executors page contains two tabs:

  • ETL Executors: You can manage executors used for ETL processes.
  • Code Executors: You can view, modify, or remove code executors used for script and code execution.

Administrators can configure and manage executors based on operational requirements.

LLM

The LLM component enables you to manage the platform’s large language model capabilities. It helps you organize and control both the models available in the platform and the LLM agents configured to use them for specific tasks or workflows. This component is useful for supporting intelligent automation, improving productivity, and simplifying language-based operations.

  • LLM Models: Enable you to view and manage the large language models available in the platform. It helps you identify the models suitable for different AI-driven tasks and manage them from a single place.
  • LLM Agents: Enable you to view and manage LLM agents that are configured to use the available language models. It helps you organize agents created for specific tasks, workflows, or automation needs.

Notification Destinations

The Notification Destinations component enables you to set up notification channels used across different parts of the platform. It enables you to configure where and how the system alerts are sent. By default, the platform includes Webhook and Email as built-in notification channels. These channels deliver notifications triggered by system events, tasks, or rules, ensuring alerts reach the correct recipients or systems.

Query Console

The Query Console component enables you to create, save, edit, and run scripts against selected data sources. It helps you organize scripts into folders for easier management and reuse. This feature is useful for testing queries, validating data, and streamlining script execution without switching between multiple tools. Its editor experience is similar to a query editor, making it easier for you to work efficiently with scripts and data operations.

User Management

The User Management component enables you to manage user access to the platform. It provides a centralized location to create and manage users, organize users into groups, and configure roles and permissions.

It enables you to ensure that users have access to the features and data required for their responsibilities while maintaining appropriate access controls across the platform.
