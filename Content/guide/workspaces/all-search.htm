Using All Search

The All Search feature enables you to search across the data available in the current case and locate relevant profiles, records, and content. You can refine the search by using keywords, date ranges, geographic areas, profiles, profile sets, and identifiers.

Use the search bar and filters to define the information that you want to find.

The following table explains the search options and filters to find information:

Search Filters Description
Search this case

Enables you to enter keywords, phrases, or identifier values and search the data available in the current case.

Tip: Separate multiple values with commas and use quotation marks to search for an exact phrase.
All

Enables you to display matching Profiles, records, and content in the search results.
Profiles Enables you to display only matching profiles in the search results.
Records Enables you to display only matching records in the search results.
Content

Enables you to display only matching case content in the search results.
Date range

Enables you to select a time period and limit the search results, such as the last 24 hours.

  • To add a date range, click Last 24 hours and select a predefined date range.
  • To add a customized date range, click Last 24 hours, enable the Absolute toggle icon, and select the required date range.
Similarity Search

Enables you to upload a face image, an image, or a voice sample and search for matching profiles, records, or content.

To upload an image or an audio file, click the Attachment icon and upload relevant file.
Upload Identifiers (CSV)

Enables you to upload a CSV file containing a list of identifiers and use them as search criteria.

To upload a CSV file containing identifiers, do the following:

  1. Click the Upload Identifiers (CSV) icon. The Upload Identifiers pop-up is displayed.
  2. Click within the Click or drag a CSV file here to upload area and upload the relevant CSV file.
  3. Map the columns from the CSV file with the columns in the available data base table columns and click Next.
  4. Review the mapping and click Add identifiers. The identifiers in the select CSV file are added to the search criteria.
Add area

Enables you to define a geographic area and limit the results to records associated with that area.

To add a geographic location, do the following:

  1. Click Add area. All existing areas are displayed in the Select area pop-up.
  2. Select the relevant areas or draw new areas as required and click Apply.

Note: For more information about drawing areas on a map, see Drawing Areas.

Add Profiles and Profile Sets

Enables you to select one or more profiles or profile sets and limit the results to records linked to those profiles.

To add Profiles or Profile Sets to your search criteria, click the More (3 dots) icon, and select Add profiles or + Add sets.

Note: For more information about searching for Profiles and Profile sets, see Profile Search.
Add identifier

Enables you to select an identifier type and enter one or more values to limit the results to records containing those identifiers.

To add specific identifiers to your search criteria, do the following:

  1. Click the More (3 dots) icon, and select + Add identifiers.
  2. Select the identifier type and enter relevant values.
Note:
  • All Search searches only the data available in the current case. The results depend on your access permissions and the data configured for the case.
  • You can combine search categories and filters, such as Profiles, Records, Date range, and Add area, to narrow the results.
