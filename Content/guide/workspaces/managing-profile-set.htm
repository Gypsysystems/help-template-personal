Managing a Profile Set

The Profile Sets in a workspace sidebar displays all saved profile sets.

Note: For information about saving Profiles as a Set, see Saving Profiles as a Set.

This section provides information about managing a Profile Set.

In this Topic

  • Exporting a Profile Set
  • Moving or Copying Profiles to Another Profile Set
  • Deleting Profiles from a Profile Set
  • Deleting a Profile Set

Viewing and Modifying Details of a Profile Set

To view a Profile Set and modify its details, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click the Profile Sets icon. All saved profile sets are displayed.
  4. (Optional) In the Search bar, enter partial or full name of the profile set. The profile sets are filtered based on the entered keyword.
  5. (Optional) In the Profile list, you can do the following:
    • To view a Profile's details in the Profile Details pop-up, click the Details link for that Profile.
    • To view a Profile's details in a new tab, click the Open in tab link for that Profile.
  6. To view the details of a Profile Set, click the name of that profile set. The details of the Profile Set are displayed on a new tab.
  7. You can modify the following details of a Profile Set:

    Field

    Description

    NameThe name of the Profile Set.
    Type

    The available predefined Profile types, such as:

    • POI (Point of Interest)
    • Suspect
    • Target
    Description (Optional)The description of the Profile Set.
  8. Click Save Changes. The changes are saved and a confirmation message is displayed.

Moving or Copying Profiles to Another Profile Set

To move Profiles from one Profile Set to another Profile Set, do the following:

  1. Log in to Synergy and open the workspace of interest.
  2. Click the Profile Sets icon. All saved Profile Sets are displayed.
  3. Search and click the Profile Set of interest. The details of the Profile Set are displayed on a new tab.
  4. In the Profile list, select the Profiles you want to move.
  5. On the upper-right corner of the Profile list, click the Move to another Set icon. The Move profiles to another set pop-up is displayed.
  6. From the Move to drop-down, select the profile set to which you want to move the selected profiles.

    Note: The Move to drop-down displays only the Profile Sets available in that workspace.

  7. (Optional) To copy the selected Profiles to the selected Profile Set, enable the Copy mode toggle icon.
  8. Click Submit. The selected Profiles are moved to the selected Profile Set and are removed from the current Profile Set.

    Note: If you have enabled the Copy mode, the selected Profiles are copied to the selected Profile Set.

Exporting a Profile Set

To export data from a Profile Set, do the following:

  1. Log in to Synergy and open the workspace of interest.
  2. Click the Profile Sets icon. All saved Profile Sets are displayed.
  3. Search and click the Profile Set of interest. The details of the Profile Set are displayed on a new tab.
  4. On the upper-right corner of the Profile list, click the Export set icon. The Export profile set(s) pop-up is displayed.
  5. To export Profile details, do one of the following on the Profiles tab:
    • To export all the details of the Profiles in the Profile Set, click the Select all checkbox.
    • To export specific details of the Profiles in the Profile Set, click the relevant checkboxes.
  6. To export data from a schema, do the following on the Data tab:
    1. To export data for a specific time range, click Last 7 days and then select a relevant predefined time range.
    2. From the Select a schema drop-down, select a schema and click Add. All the data fields available in the selected schema are displayed.

      Note: By default, all data fields are selected. You can deselect the data fields you do not want to export.

    3. (Optional) Click the Schema filters icon to specify values that you want to export.
    4. (Optional) Enable Add profile attributes toggle icon and select the required attributes you want to export.
  7. Do one of the following based on your selection:
    • To export Profile details, click Submit on the Profiles tab.
    • To export data from a selected schema, click Submit on the Data tab.

    Based on your selection, the data is exported to the default download folder on your computer.

Deleting Profiles from a Profile Set

To delete Profiles from a Profile Set, do the following:

  1. Log in to Synergy and open the workspace of interest.
  2. Click the Profile Sets icon. All saved Profile Sets are displayed.
  3. Search and click the Profile Set of interest. The details of the Profile Set are displayed on a new tab.
  4. In the Profile list, select the Profiles you want to delete.
  5. On the upper-right corner of the Profile list, click the Delete icon. The selected Profiles are displayed in the Delete profiles from set pop-up.
  6. (Optional) To view a Profile details on a new tab, click the Open in tab link for that Profile. The Profile details are displayed on a new tab.
  7. To delete the selected Profiles, on the Delete profiles from set pop-up, click Submit. The selected Profiles are removed from the Profile Set.

Deleting a Profile Set

To delete a Profile Set, do the following:

  1. Log in to Synergy and open the workspace of interest.
  2. Click the Profile Sets icon. All saved Profile Sets are displayed.
  3. Search and click the Profile Set of interest. The details of the Profile Set are displayed on a new tab.
  4. In the Details section, click Delete. A confirmation message is displayed.
  5. Click OK to confirm. The entities affected by the deletion of the Profile Set are displayed in the Delete profile set pop-up.
  6. Verify the details and click Submit. The Profile Set is deleted from the workspace.
