Viewing Data Sources in a Workspace

Data Management enables you to navigate across workspace data sources in a hierarchical tree structure. You can view database schemas, tables, columns, and associated data types.

Note: The Data Management component is available for Data Engineers with relevant permissions.

To view the data sources available to you and their details, do the following:

  1. Log in to Synergy
  2. From the Management drop-down, select Data Management. All data sources allocated to the workspace are displayed.
  3. You can do the following:
    • Expand the data sources to view the buckets, folders, and files available in it.
    • Right-click the data source and click Sync to sync the data within the data source.
  4. (Optional) To create a folder in a minio data source bucket, do the following:
    1. Expand a minio data source. All available data source elements are displayed.
    2. Right-click the data source bucket in which you want to create a folder and then click Create Folder. The Create a new Folder pop-up is displayed.
    3. Enter a name and a description for the folder and click Save. A new folder is created and is displayed under the selected data source bucket.

      Tip: You can right-click a folder and click Create Folder to create a folder within a folder.

  5. (Optional) To upload a file to a folder, do the following:
    1. Expand a data source bucket and right-click the folder in which you want to upload a file.
    2. Click Upload File. A pop-up is displayed.
    3. Click anywhere within the upload section. The Open window is displayed.
    4. Browse and select the file you want to upload and then click Open. The uploaded file name is displayed in the Upload File pop-up.
    5. Click Upload to upload the file into the selected folder. The selected file is uploaded and displayed under the selected folder.
  6. (Optional) To view the details of a folder, data table, folder, or a file, right-click the relevant element and click Open details for that element. The Item Details pop-up is displayed.

    The following table explains the fields you can view in the respective data source elements:

    Element

    Description

    Data Table

    Displays the following details of the data table:

    Field

    Description

    NameDisplays the name of the data table.
    Data SourceDisplays the Data Source name in which the data table is available.
    SchemaDisplays the schema name in which the data table is available.
    DescriptionDisplays the description of the folder.

    You can do the following in the Item details pop-up for a data table:

    • Add or remove columns.
    • View and configure Lineage.
    • View and configure indexes.
    • View the projection details.
    • View and configure TTL.
    • View the partition details.
    • View the activity history in the data table.
    • View the DDL Statement.
    • Run the data table to preview the results.
    Folder

    Displays the following details of the folder in the General tab:

    Field

    Description

    NameDisplays the name of the folder.
    Data SourceDisplays the Data Source name in which the folder is available.
    BucketDisplays the Bucket name in which the folder is available.
    PathDisplays the folder path.
    DescriptionDisplays the description of the folder.
    Statistics tabDisplays the activities performed within the folder.
    File

    Displays the following details of the file in the General tab

    Field

    Description

    NameDisplays the name of the File. You can modify the name, if required.
    Data SourceDisplays the Data Source name in which the File is available.
    BucketDisplays the Bucket name in which the File is available.
    Extension typeDisplays the file extension. For example, csv.
    PathDisplays the File path.
    • You can do the following in the Column tab:
      • View existing columns.
      • Add a new column.
    • On the Statistics tab, click Refresh to view the statistical data of the file.
    • On the Preview tab, you can add parameters and run queries.
