About this User Manual

This comprehensive Synergy User Manual assists you to fully explore and understand each feature of Synergy. The User Manual is designed both as a course in using Synergy, and as an ongoing reference when working with the application. You can quickly access specific topics for easy reference and refer to the User Manual for additional information.

Audience

The audience for this User Manual is users of Synergy, who are Analysts and Investigators who perform data analysis and resolve specific use cases by searching, viewing, exploring, discovering, and reporting on various data sets.

The audience for this User Manual includes system administrators, IT managers, security administrators, and data engineers who configure, manage, and maintain the Synergy. They ensure data integration, system performance, and user access to support reliable data use across the organization.

How to use this User Manual?

Each page in the User Manual is called a Topic. Main topics group related sub-topics together.

The following table lists the components of the User Manual that facilitate quick and easy navigation and can enable you to find the information you require easily.

User Manual Component Description
Search To find information about any capability or feature of the application or the procedure to perform a task, enter keywords in the Search bar in the upper-right corner of any page.
Left-side Table of Contents (TOC) All topics and sub-topics are listed in a logical order. Click on the main topic to view its content and its sub-topics. Click on a specific topic on the left-side TOC panel to view the content on the right-side frame.
Breadcrumb A trail that allows you to keep track of the topic location that you're currently viewing in the User Manual. Click the hyperlink navigates you back to the main topic.
Topic Toolbar

Topic Toolbar Element

Description
Remove Highlights When you search for keywords in this User Manual, the search results that match the keywords and phrases are highlighted when the individual topics are opened. Click the Remove Highlights button to remove the highlights.
Print Click the Print button to print the current page that you are viewing.
Navigate next If you prefer reading the User Manual in a sequential order, just like you would do in a book, click the Navigate next button.
Navigate previous Click Navigate previous button to go to the previous page.
Fields and Buttons

All field and button names in the User Manual are denoted by bold font.

Example: Enter the User Name and Password, and click Sign in.
Location / Path

All locations and paths in the User Manual are denoted by bold and italics font.

Example: Go to Visualize > action_type visualization.
Messages (Warnings, Success, Error, etc.)

All messages in the User Manual are denoted by italics font.

Example: On successful deletion, a message “Success, visualization was deleted” is displayed.
Notes, Tips, Example, Info, Warning

The following elements in the User Manual are placed within a stylized box.

Examples:

Note: Sample Note text.

Example: Sample Example text.

Tip: Sample Tip text.

Info: Sample Info text.

Warning: Sample Warning text.
Back to Top Click Back to Top icon at the bottom right to quickly navigate to the top of the page.
