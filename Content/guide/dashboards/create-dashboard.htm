Creating Dashboard

Dashboard enables you to organize and analyze data using visual components and interactive filters. A dashboard is created using a selected schema and can include selectors, tabs, and view‑level settings.

Dashboard displays visualizations that help you to understand and analyze your data in a workspace. Visualizations are in the form of charts, data, and maps.

To create a dashboard, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. From the Admin drop-down, select System Dashboard. All available system dashboards are displayed.
  4. Click the vertical three dots menu next to the search bar and select New Dashboard. The New Dashboard tab is displayed.
  5. Click + Add. The Dashboard settings pane is displayed.
  6. Enter the following dashboard details:

    Field

    Description

    NameEnter a name for the dashboard.
    Visibility

    Specify the dashboard visibility level.

    • Shared makes the dashboard available to other authorized users.
    • Private restricts access to the dashboard owner.
    Schema (Optional)Select the schema used as the primary data source for the dashboard.
    Icon (Optional)Select an icon to represent the dashboard.
    Tags (Optional)Type and select the tag to apply it to the dashboard.
    Show title (Optional)Displays or hides the dashboard name on the dashboard header.
  1. (Optional) From the Appearance section, select a color theme for the dashboard.
  2. To configure Filters in your dashboard, do the following:

    Field

    Description

    Time filterEnable or disable time‑based filtering for the dashboard.
    Default range

    Select the default time range that applies when the dashboard opens.

    Note: Enable the Time filter to set a default range.

    Schema filters

    Enable or disable schema-level filters at the Dashboard level, automatically applying the selected filters across all widgets with the same schema set.

    To set a schema filter, do the following:

    1. Enable the Schema Filters toggle icon.
    2. Click Add filter. The Add filter field pop-up is displayed.
    3. Do one of the following:
      • To enter an expression, enable the Expression toggle icon, enter the expression in the text box, and click Apply.
      • To select specific columns and create a filter criterion, do the following:
        1. With the Expression toggle icon disabled, from the Select field drop-down, select the relevant field.
        2. From the Select an operator drop-down, select the relevant operator.
        3. Switch between Field and Value as required. For example, score > threshold.

          Note: This option is available only for the following operators: =, !=, >, <, <=, >=, Starts With, Ends With, Contains, and Does Not Contain.

        4. Enter a Value or select a relevant Field based on your previous selection.
    4. Click Apply. The filter is displayed in the dashboard header.
    Profiles FilterEnable to apply Profile filters across all widgets in the dashboard.
    Selectors

    Enables you to add custom selectors to filter data in the dashboard.

    To add a selector, click Add Selector, then configure Label Settings, UI Control Settings, Widget Mapping, and Direct Mapping in the Selector settings pop-up, as required.

    Selectors > Label Settings

    To configure the Label settings, in the Label settings section, do the following:

    Field

    Description

    PinnedEnable to pin the selector to the dashboard header.
    RequiredEnable to make the selector a mandatory field before loading data.
    LabelEnter a label name for the selector.
    Label positionSelect Left, Top, or Hidden to specify the label position.
    HintEnter a tooltip for the selector.
    Selectors > UI Control Settings

    To configure the selector UI settings, in the UI Control Settings section, do the following:

    Field

    Description

    TypeSelect the selector control type.
    MultipleEnable to allow selection of multiple values.
    MultilineEnable to allow multiline display for selector values.
    Source

    Enables you to select the data source schema or enter manual values for the selector.

    To select schema as the data source, select Schema, and do the following:

    1. Schema: Select the schema used to populate the selector values.
    2. Value field: Select the field used as the selector value.
    3. Label field: Select the field displayed as the selector label.

    To enter the data source manually, do the following:

    1. Select Manual. The Options list field is displayed.
    2. Enter the values and press Enter to add them.

      Note: You can paste a comma-separated or newline-separated list.

    Selectors > Widget Mapping

    To map fields to the widget, in the Widget mapping section, do the following:

    Field

    Description

    Schema fieldSelect the schema field the selector is mapped to, then select a relevant operator.
    ParameterEnter the parameter name used for filtering.
    IdentifierSelect the identifier type, if applicable.

    Note: The filter is applied only if the widget’s schema contains a field with the exact same name specified in the selector configuration.

    Selectors > Direct Mapping

    To directly map the selector to a widget, in the Direct mapping section, do the following:

    1. From the Select a widget drop-down, select the widget to which you want to add the selector.
    2. From the Select field drop-down, select the field you want to include.
    3. Select a relevant operator and click Add. This maps values directly from the selected source field without additional transformation or processing.
  1. In the Dashboard Pages/Tabs section, click Add tab to add new tabs for your dashboard.
  2. To configure your dashboard, in the View Settings section, enter the following:

    Field

    Description

    Open behaviorSelect how the dashboard opens.
    InteractiveEnables or disables interactive mode.
    Home pageSets the dashboard as the home page.
  3. Click Save. The new dashboard is displayed in the Available dashboards pane.The New Dashboard pop-up is displayed with the selected visuals.
  4. Enter the following details:

    Field

    Description

    NameA name for the dashboard.
    Icon (Optional)An icon for the dashboard.
    Color (Optional)A color for the icon.
    Tags (Optional)

    A name for the tag.

    Note: Tag helps members of the workspace to know the intent of this dashboard.

    Folder (Optional)Saving location for the dashboard.
  5. Click OK. The dashboard is saved and is available in the Content component of your workspace.

Creating Widgets

Widgets are visual components added to a dashboard to display data in tabular or graphical form. Each widget is created using a selected schema and configured using widget‑specific settings.

Note: Widget configuration options vary depending on the selected widget type.

To add a widget to a dashboard, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click Dashboards and select the required dashboard.
  4. Click the edit icon in the upper-right corner of the dashboard.
  5. From the Canvas toolbar, drag and drop the Add Widget icon into the Canvas.
  6. From the Create Widget side pane, select the relevant widget type. For example, Grid.
  7. Click Create. The selected widget type is added to the canvas and the Widget settings pane is displayed.
  8. On the Widget settings pane, in the Visualization settings section, do the following:

    Field

    Description

    TitleEnter a title for the widget.
    SchemaSelect the schema used as the data source for the widget.
    Hide headerHides the widget header.
    No backgroundRemoves the widget's background styling.
  9. (Optional) On the Widget settings pane, in the Filter section, do the following:
    1. Click the Filter icon.
    2. Select the field to filter.
    3. Select the operator.
    4. Enter or select the filter value.
    5. Click Apply.

  1. (Optional) On the Widget settings pane, in the Columns section, do the following:

    1. From the drop-down, select the fields you want to use for the widget.

    2. To create a custom field, click Custom Expression and do the following:

      Field

      Description
      Alias Enter a name for the field.
      Expression Expression enables the use of a calculated value instead of a direct schema field. The expression field is used to enter the logic that defines how the value is calculated.
      Aggregation Aggregation defines how the expression result is calculated when multiple records are involved. You can select an aggregation method to control how values are combined, such as sum, average, or count.

    3. Click Apply.

  1. (Optional) On the Widget settings pane, in the Sorting section, do the following:

    1. Select a field you want to use for sorting.

    2. Click ASC or DES order to sort the data on the widget.

  1. (Optional) On the Widget settings pane, in the Result size section, specify the maximum number of records to be displayed in the grid.

  2. To configure grid options, on the Widget settings pane, click the Options tab and do the following:

    Field

    Description
    Autosize columns Automatically adjusts column widths.
    Show row numbers Displays row numbers in the grid.
    Show sidebar Displays the grid sidebar.
    Show pagination Enables pagination for grid results.
    Page size Specifies the number of rows per page.
    Open details column Displays a details column for each row.
    Row height Specifies the height of grid rows.

  3. Click Apply.

  4. Click Save to save the Dashboard.

Creating Widgets using AI

Synergy provides an AI Assistant that lets you generate widgets with natural-language instructions. The AI Assistant creates widgets based on the selected schemas.

To add a widget to a dashboard, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click Dashboards and select the required dashboard.
  4. Click the edit icon in the upper-right corner of the dashboard.
  5. From the Canvas toolbar, click AI Assistant. The AI Assistant pop-up is displayed.
  6. In the Instruction field, enter a natural language instruction describing the dashboard to be created. For example, Generate a dashboard using the employee_data schema.
  7. Click Generate. The AI Assistant generates configuration for the dashboard.
  8. Click Apply. The widgets are created.

Adding Notes to the Dashboard

Notes can be added to provide additional information or guidance.

To add a note, do the following:

  1. Drag and drop the Note component onto the dashboard canvas.

  2. To configure the note settings, do the following:

    Field

    Description
    Variant Select the note type. Available options include Clear, Info, Tip, Warning, and Important.
    Content Enter the note text.

  3. Click Apply to save the note.

  4. Click Save to save the dashboard.

Adding Headers to the Dashboard

Headers are used to label or group sections within a dashboard.

To add a header, do the following:

  1. Drag and drop the Header component onto the dashboard canvas.

  2. To configure the header settings, do the following:

    Field

    Description
    Header text Enter the header text.
    Background color Select the background color for the header.
    Font color Select the font color for the header text.
    Font size Specify the font size.

  3. Click Apply to save the header.

  4. Click Save to save the dashboard.
