Creating a Profile Type

Profile Type enables data engineers to create and configure Profiles using identified entities, identifiers, and attributes. It connects data between Profiles (entities) and schemas. It also supports Profile ingestion steps within data pipelines.

Profile Types define how related identifiers and attributes are grouped to represent a real‑world entity in Synergy. A Profile Type determines which identifiers can be associated, how Profiles appear in the user interface, and how data is consolidated during profile ingestion.

Note: Profile Type configuration also controls how Profiles are displayed in components such as Profile cards, Graph Analysis nodes, and the Profile Details page.

To create a profile type, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Entity Configuration. All existing entity configurations are displayed in the Entity Configuration page.
  3. From the New drop-down, select Profile Type. The New Profile Type section is displayed.
  4. In the General tab, enter the following:

    The General tab enables you to enter essential details, such as name, icon, color, and description, and to select identifiers when creating a Profile Type.

    Field

    Description

    NameEnter a name for the Profile type.
    IconSelect an icon for the Profile type from the drop-down list.
    ColorSelect a color for the Profile type from the color picker.
    Order

    Enables you to define the position of the profile type in profile-type selectors. Synergy displays lower values first.

    Leave the field blank to sort the profile type alphabetically after the explicitly ordered entries.

    DescriptionEnter a description about the Profile type.
    All SearchEnables you to include profiles of this type in All Search results. Turn off the toggle to exclude the profile type from All Search.
    Identifiers

    Select the identifiers you want to include in a Profile table from the drop-down list.

    TagsEnables you to assign tags to the profile type for classification, filtering, and easier identification.
  5. Click Save. The new Profile type is saved and displayed in the Entity Configuration pane under Profile Types.
  6. In the Attributes tab, click Add Attribute. The Add New Attribute pop-up is displayed.

    The Attributes tab enables you to add and configure attributes for a Profile Type by defining their properties and behaviors.

  7. In the Add New Attribute pop-up, enter the following:

    Field

    Description

    NameEnter a name for the Profile type.
    DescriptionEnter a description for the Profile type.
    Value TypeSelect the data value type from the drop-down list.
    FormatSelect the format of the attribute value type from the drop-down list.
    Is Nullable

    Enable the toggle icon to indicate that the attribute can be empty.

    Show in Profile SearchEnable the toggle icon to indicate that the attribute should be searchable in Profile Search.
    Always on ScreenEnable the toggle icon to indicate that the attribute can be displayed always on the screen.
    Input Type

    Select the input type for this attribute. The following input types are available:

    • Select: Enables you to select one value from the drop-down.
    • Multiple: Enables you to select multiple values from the drop-down.
    • Plain: Enables you to enter plain text.
    Value PlaceholderEnter a placeholder text for the attribute value field. For example, select the Marital status of the Profile.
    Match Type

    Select the Match Type for the attribute value. The following Match Types are available:

    • Exact: Matches the attribute values exactly as entered.
    • Like: Matches the attribute values based on a partial pattern.
    • FTS (Full-Text Search): Matches attribute values using a full-text search, allowing more flexible text matching.
    System attributeSelect the matching system attribute.
  8. In the Input options section, do the following:
    1. In the Value field, enter a value for the attribute.
    2. In the Label field, enter a label for the attribute.
    3. Click Add. The Value and the Label are displayed in the Input options section.
  9. Click Apply. The attribute is displayed in the Attribute tab.
  10. Go to the UI Cards tab and select the relevant attributes and identifiers in the following sections:

    The UI Cards tab lets you configure the attributes and identifiers displayed in search cards, mini cards, and the profile details sidebar.

    Section

    Description

    Search card configThe selected attributes and identifiers to use when performing a Profile search.
    Mini card configThe selected attributes and identifiers are displayed on the Profile card preview.
    Profile details sidebarThe selected attributes and identifiers are displayed in the Profile Details section.
  11. Go to the Activity tab and do the following:

    The Activity tab enables you to configure time-based records, schemas, date ranges, and dashboards for Profile activities.

    Element

    Description

    Activity TabEnable the toggle icon to display all records with a time field in the Profile cards.
    Identifiers and Attributes TabEnable the toggle icon to display the Identifiers and Attributes in the Profile cards.
    Other Records TabEnable the toggle icon to display the time-based information in the Profile cards.
    Default date rangeSelect the default date range to be displayed when performing a Profile search.
    Schemas to querySelect the required schemas to retrieve Profile events on the Activity tab.
    DashboardsSelect the dashboard in which you want to display the Profile details. You can also create visualizations. For more information about creating visualizations, see Creating Dashboard.
  12. Click Save. The Activities for the Profile Type are defined.
  13. Go to the Reports tab and do the following:

    Element

    Description

    Available TemplatesSelect a relevant template for your report.
    + (Add Template)Click + (Add Template) to create a report template.
    TitleEnter a title for the report.
    WatermarkEnter a text to insert it as a watermark on the report.
    LandscapeEnable the toggle icon to switch the report to landscape orientation.
    RTL (Right-to-Left) Text DirectionEnable the toggle icon to change the text direction in the report to right-to-left.
  14. Modify the codes in the following tabs to make changes in the report:
    • HTML
    • Main
    • Table
    • Profile
    • Sample
Tip:

After configuring the report, you can do the following:

  • Click Download at the top of the report to download the report.
  • Click Preview to preview the report. To return to the report edit mode, click Edit.
  1. Click Save to save the report.

The new Profile Type is created and is displayed under Profile Types.
