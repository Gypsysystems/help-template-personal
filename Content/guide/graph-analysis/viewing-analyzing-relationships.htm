Viewing and Analyzing Relationships

You can add Profiles on the Canvas and analyze them using various Link Analysis tools.

In this Topic

  • Identifying Relationships between Profiles Using Schemas
  • Link Analysis Tool Operations

Adding Profiles to Canvas

You can add Profiles on the Canvas and analyze them using various Link Analysis tools.

To view and analyze relationships in Link Analysis, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Mouse over Tools and select Link Analysis. The Link Analysis component is displayed.
  4. To add Profiles, click the Add to graph (+) icon. The Profile Search pop-up is displayed.
  5. In the Profile Search pop-up, do the following:
    1. From the Profile Types drop-down, select the relevant Profile type .
    2. To search Profiles based on names or attributes, enter a keyword.
    FieldAction
    Profile type

    From the drop-down, select a Profile type. For example, Individual. By default, All Profiles is selected.

    Note: The remaining fields in the Profile search pane appear based on the selected Profile type.

    Keyword (Optional)Enter a name or an attribute to find the relevant Profiles.

    Enter the name of the Profile.

    Tip: Enable Exact match to find matching Profiles.

  6. In the Link Analysis component, click the Save icon. The New Link Analysis pop-up is displayed.
  7. Enter the following details in the New Link Analysis pop-up:

Note: Additionally, you can navigate to Identifiers, Sets, Collections, and Records tab to search and add matching records.

Identifying Relationships between Profiles Using Schemas

You can identify the relationships between multiple Profiles or search and add specific Profiles based on schema on the Canvas using the Expand by Search feature.

To identify relationships between Profiles using schemas, do the following:

  1. After adding relevant Profiles on Canvas, select the Profiles for which you want to find relationships on the Canvas.
  2. In the Analysis toolbar, click the Expand by search icon. The Expand by search pop-up is displayed.
  3. From the Select a Schema drop-down, select a relevant schema based on which you want to find Profiles. For example, to search for Profiles who had communicated through SMS with the selected Profiles on the Canvas, select the SMS schema.

    Note: Schemas are displayed based on the data source allocated to the workspace.

  4. From the Time Range filter, select a predefined time range or specify an absolute time range. Link Analysis finds relationships between Profiles for the specified time range.
  5. (Optional) Click the Add filter icon to add any additional filter criteria to your search result.
  6. From the Expand by Attribute drop-down, select an attribute based on which you want to search for Profiles and then click Search. For example, if you want to search for Profiles who have communicated through messages, then select Message.

    Note: The attributes are displayed in the Expand by Attribute drop-down based on the schema selected in the Select a Schema drop-down.

    The number of Profiles found based on the selected schema and the selected attribute are displayed.

  7. (Optional) To specify a color for the Edges connected to the newly identified Profiles on the Canvas, click Select edge color and select a color from the color box at the lower-left corner in the Expand by search pop-up.

    Tip: Use this feature where you are finding multiple relations between Profiles. The color of the Edges indicate the relation type between the Profiles.

  8. To add the search result to the Canvas, click Apply. The search result is added to the Canvas and the Edges with the specific color indicates the relationship between the newly added Profiles and the existing Profiles on Canvas.

Link Analysis Tool Operations

You can use the following Link Analysis tool operations available in the Analysis tools section:

Analysis Tool Description
Expand Enables you to add directly-connect Nodes to the Canvas.
Expand by search Enables you to find Profiles connected by schemas
Fetch relations Enables you to find the relationship between selected Nodes on the Canvas or for all the Nodes on the Canvas.
Find connected profiles Enables you to find Profiles that are connected with the selected identifier.
Find the shortest path Enables you to find the shortest connection Nodes (shortest path) between two selected Profiles.
Remove selected Enables you to remove the selected Nodes on the Canvas.
Keep only selected Enables you to remove the Nodes that are not selected on the Canvas and retain the Nodes that are selected.
Save set

Enables you to save the Profiles that are selected on the Canvas as a Profile Set.

Note: For more information about saving Profiles as a set, see Saving Profiles as a Set.
