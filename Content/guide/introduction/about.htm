About Synergy

Synergy is an integrated AI data management platform designed to handle data-related tasks, including ETL (Extract, Transform, Load) and AI transformations, which enables you to apply complex business logic to your data. Additionally, it enables users across your organization to search, access, and analyze the same data and collaborate as a team.

Synergy includes a mass profiling framework that enables deeper analysis than a table-only view by consolidating entity information (for example, employees, customers, or digital identities) into unified Profiles and connecting those Profiles using identifiers, relationships, and involvement types.

Synergy Components

Following are the core components of Synergy:

  • Data Management
  • ETL Pipeline
  • Data Catalog
  • Explorer
  • Map Explorer
  • Profile Search
  • Link Analysis
  • Dashboard
  • Executors
  • Collections
  • Data Monitors
  • Data Quality
  • AI Assistant
  • Reports

Data Management

The Data Management component enables you to organize and analyze data from various sources associated with a workspace.

In the Data Management component, you can:

  • Query data sources.
  • Create schemas.
  • Synchronize data sources with the workspace.
  • Manage analytical schemas within schemas.
  • View and manage database tables and columns.

Synergy supports data sources stored in different types of databases such as ClickHouse, S3 file storage, Minio, postgres, and so on.

For more information, see Data Management.

ETL Pipeline

You can transform data from various structured and unstructured sources following best ETL practices using the Pipelines component. This component lets you define parameters, conditions, and dependencies for each step. It also enables you to write and execute custom SQL queries and use Python to create and run ML models based on existing data. For example, you can set a condition to run an ML step only if the previous SQL or Explorer step returns search results, or if the ML model finds any expected values.

For more information, see Searching for Data using Pipeline.

Data Catalog

Data Catalog enables you to store and organize analytical data, such as schemas, within the platform and its workspaces. It enables you to view and modify the schemas. You can query schemas and create dashboards for them.

For more information, see Working with Data Catalog.

Explorer

Explorer enables you to search for data using database schema. A Schema in Synergy is a logical view of a data source table. For example, a Calls schema only consists data related to call records.

The schemas are available to a workspace depending on the data source assigned to the workspace.

Data Explorer enables you to:

  • View the search results in a grid, map, or on a timeline.
  • Aggregate, apply metrics, and group and sort data without any programming knowledge.
  • Explore schema data in grid and chart formats.
  • Apply filters, sort data, and save Explorer configurations for reuse.

For more information, see Explorer.

Map Explorer

Map Explorer enables you to visualize, analyze, and interact with geospatial data directly on an interactive map. You can also plot location‑based datasets, overlay multiple layers from different schemas, define geographic areas, and analyze movement patterns.

For more information, see Map Explorer.

Profile Search

Profile Search is a search engine that enables you to search for Profiles across various data sources. You can enter names and/or identifiers, and/or use advanced filtering to define your search scope. You can also load a previously-saved set and search within the set.

Note: A Profile can be a person, organization, or any type of entity whose data and identifiers derived from different data sources are collated, organized meaningfully, and presented conveniently in its respective Profile Details tab.

After you perform a search, the search results are displayed as Profile Cards. Each Profile Card displays the summary of the details of the Profile. You can click any Profile Card to view and analyze the Profile's details and behavior from the Profile Details tab. You can also save the Profile Search configurations even if no results are returned. Saved searches can be reused later with the same search criteria.

For more information, see Profile Search.

Link Analysis

Link Analysis enables you to visually explore relationships between Profiles, identifiers, and events. It allows you to build and analyze networks by adding nodes to a graph, expanding connections, and performing relationship‑based analysis.

You can load a previously-saved Profile sets and analyze connections between Profiles and identifiers represented as Nodes and Edges.

For more information, see Link Analysis.

Dashboard

A dashboard is an information aggregation and visualization platform that enables you explore and analyze different kinds of data. Dashboards enable you to create visualizations using schema and interact with them. These visualizations are in the form of chart, data, and map. It helps you to investigate and analyze relevant data.

Note: Dashboards are created using schema-level data only.

For more information, see Dashboards.

Executors

The Executors component automates task execution in a data pipeline by monitoring specific events, such as the arrival of new data files, and triggering the appropriate tasks to maintain a smooth data flow. It enables you to register the existing executors already deployed in your environment.

You can create ETL Executors or modify the existing code executors.

Executors provide the execution environments that Synergy uses to run data processing tasks and custom code. The Executors page contains two tabs:

  • ETL Executors: You can manage executors used for ETL processes.
  • Code Executors: You can view, modify, or remove code executors used for script and code execution.

Administrators can configure and manage executors based on operational requirements.

For more information, see Using the Executors Component.

Collections

The Collections component enables you to group selected records retrieved from the Explorer into a reusable collection for in-depth investigation and analysis.

It enables you to organize relevant records, review their associated profiles, and compare collections using set operations.

Once your data is prepared and published, you can utilize the Collections to gather useful records, examine related entities, and maintain a working set focused on your investigation.

Note: You can use Collections only when the selected schema has a primary key defined in the catalog.

Data Monitors

Data Monitors enable you to create scheduled searches within a case and automatically identify new records that match defined criteria. Each monitor runs at the configured interval, compares the results against records identified in previous runs, and surfaces only new matches.

You can configure a monitor to:

  • Search one or more schemas within the case.
  • Apply profile, date, keyword, geographic, and schema-specific filters.
  • Run automatically based on a predefined or custom schedule.
  • Search data within a defined lookback period.
  • Route new matches to an existing collection or create a new collection for each run.
  • Notify selected users or groups when the monitor identifies new matches.
  • Preview the results using a dry run before activating the monitor.

Note: Data Monitors operate within the workspace where you create them and search only data in that workspace.

Data Quality

The Data Quality (DQ) component enables you to evaluate the accuracy, completeness, consistency, and validity of data stored in Synergy. You can define reusable data quality rules and apply them to tables or include them as steps within data pipelines.

You can use the following DQ features to ensure data quality:

  • DQ Rule: Defines the condition that Synergy evaluates against a table column.
  • DQ Check: Applies the configured rules to a table and provides data quality results.

Data Quality enables you to:

  • Create reusable DQ Rules that define business or technical expectations for data.
  • Configure DQ Checks that apply one or more rules to a selected table.
  • Run checks to assess whether table data meets the defined quality requirements.
  • Review data quality scores, statuses, and records that require attention.
  • Apply DQ Rules within pipeline steps to validate data during pipeline execution.

Note: Create the required DQ Rules before configuring a DQ Check or adding data quality step to a pipeline.

AI Assistant

The AI Assistant component enables you to ask questions in natural language and analyze data available within a case. It uses the current case context to search profiles, query data, generate charts, display media and conversations, and provide actions that open the relevant Synergy components.

The AI Assistant also considers the content that you are currently viewing. For example, when you open a profile, dashboard, or Link Analysis graph, the assistant provides starter prompts and responses related to that content.

You can use the AI Assistant to:

  • Search for profiles and records.
  • Query case data.
  • Generate charts and data grids.
  • Review media and conversations.
  • Open profiles, schemas, collections, dashboards, and other supported components.
  • Navigate to related documentation topics.
  • Continue an investigation by using suggested follow-up questions.

Note: The AI Assistant is available only within a case. It uses the data, permissions, and context associated with the current case.

Reports

Reports enable you to transform investigative information available within a Case into a structured intelligence report. You can create and format report content, add supporting evidence, apply classification markings, submit the report for review, export the approved report, and release it to selected recipients.

Reports supports a controlled workflow that helps ensure that:

  • Report content is classified before review.
  • A different user reviews the report.
  • Only approved reports are exported and released.
  • Released reports have a traceable chain of custody.

Note: Reports are available only within a case.
