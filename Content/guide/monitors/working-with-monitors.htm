Working with Data Monitors

You can create, configure, activate, and manage Data Monitors to track new records within a case and review the results of each scheduled execution.

In this Topic
  • Creating a Data Monitor
  • Configuring Data Monitor Notifications

Creating a Data Monitor

To create a data monitor, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Do one of the following:
    • Right-click the Monitors component and select New Monitor.
    • Click the Monitors icon at the upper-right corner of the navigation bar and select + New Monitor.

      The Create monitor pop-up is displayed

  4. Enter a Name and a Description for the data monitor and click OK. The newly created data monitor page is displayed.
  5. In the Details section, from the Tags drop-down, select the applicable tags.
  6. In the How often to run section, do the following:
    1. Select how frequently the monitor must run. You can select a predefined interval or enter a custom frequency.
    2. Select how far back each execution must search for matching records.

      Note: Align the lookback period with the run schedule. A lookback period shorter than the schedule leave gaps, while a longer lookback period cause the monitor to evaluate some records more than once.

      Example: If the monitor runs every 12 hours, set the lookback to 12 hours so each run searches the full period since the previous execution.

  7. In the Monitor criteria section, to configure the required search criteria, do the following:

    1. To search and add a specific profile from Profile Search, click Add profile.
    2. To add a profile set, click Add profile set.
    3. To add an identifier, click Add identifier. The identifier-specific fields are displayed.
    4. Enter the following details:

      Field

      Description

      Identifier typeSelect the type of identifier that you want to monitor.
      ValuesEnter the identifier values that the monitor must match.
      Search termsEnter keywords or terms to refine the search for matching identifiers.
      Add areaClick Add area and select the relevant geographic areas to the monitor criteria.
    5. To upload multiple identifiers, click Upload identifiers. The Upload Identifiers pop-up is displayed.
    6. Browse and upload the CSV file containing the list of identifiers.
  8. In the Schemas to watch section, click + Add schemas. The Add schemas pop-up is displayed.
  9. Select the schemas the monitor must search and click OK.
  10. To activate the data monitor, in the Details section, enable the toggle icon. The data monitor is activated and the status changes to Active.
  11. Click Save changes to save the data monitor.
  12. To test the monitor, in the Dry run section, click Dry run. The monitor evaluates the current criteria immediate and displays the matching records.

    Note: Dry run does not save an execution, update the seen ledger, write records to a collection, or sending notifications.

Configuring Data Monitor Notifications

Data monitor notifications enable you to alert selected users or groups when a scheduled execution identifies new matching records. You can configure the notification severity, labels, destinations, subject, and message for the monitor.

To configure data monitor notifications, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. In the Monitors component, select the relevant data monitor. The details of the selected monitor are displayed.
  4. In the Settings section, do the following:

    Field

    Description

    Notifications

    Enable the toggle icon to send notifications when the monitor identifies new matching records.

    Turn it off to disable notifications.

    LabelsEnter and select the labels to categorize the notification.
    Severity

    Select the notification priority. The available options are as follows:

    • Normal
    • Medium
    • Critical
    DestinationSelect the users or groups that must receive the notification.
    Save matches into collection

    To add new matches to an existing collection:

    1. Select Existing. The Select records collection pop-up is displayed.
    2. Select the collection in which you want to add the new matches and click Add. The new matches are added to the selected collection.

    To add new matches to a new collection each time the data monitor runs:

    1. Select New.
    2. In New collection name prefix enter the prefix name for the new collection. For example, investigation-anomalies.

    Note: Collections that receive records from a Data Monitor display the Sourced by monitor label.

    Max records per schemaEnter the maximum number of matching records that can be written to the collection from each schema during a monitor run.
  5. Click Save changes to save the notification settings.
