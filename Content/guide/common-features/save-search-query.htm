Saving a Search Query

The Synergy application enables you to save search queries in the following components:

  • Pipeline
  • Explorer
  • Profile Search
  • Advanced Search
  • Graph
  • Geo Search

You can save the search query you performed for future reference or other members of the workspace to view. You can do the following:

  1. Log in to Synergy.
  2. In the Workspace section, select the relevant workspace. The Content component page is displayed.
  3. Mouse over New and select Pipeline or one of the Search components as required. The relevant component's tab is displayed.
  4. Enter your search query.
  5. Click Save. A pop-up is displayed.
  6. To save a search query, enter the following details:

Field

Description
Name A name for the search query.
Icon (Optional) An icon for the search query.
Color (Optional) A color for the icon.
Tags (Optional)

A name for the tag.

Note: Tag helps members of the workspace to know the intent of this search query.
Folder (Optional) Saving location for the search query.
  1. Click OK. The search query is saved and displayed in the Content component, on the Sidebar.
  2. To use a saved search query, do the following:
    1. On the Sidebar, click Content. All the saved workspace elements are displayed in the Content component.
    2. Click the name of the search query you want to use. The search query is displayed on a new tab.
    3. Click Search on the search query. The results are displayed based on the search criteria.

      Tip: If required, modify the search query before clicking Search.
