Using the Executors Component

The Executors component automates task execution in a data pipeline by monitoring specific events, such as the arrival of new data files, and triggering the appropriate tasks to maintain a smooth data flow. It enables you to register the existing executors already deployed in your environment.

You can create ETL Executors or modify the existing code executors.

Executors provide the execution environments that Synergy uses to run data processing tasks and custom code. The Executors page contains two tabs:

  • ETL Executors: You can manage executors used for ETL processes.
  • Code Executors: You can view, modify, or remove code executors used for script and code execution.

Administrators can configure and manage executors based on operational requirements.

Adding an ETL Executor

To add an ETL Executor, do the following:

  1. Log in to Synergy.
  2. From the Admin drop-down, select Executors. All existing data executors are displayed in the ETL Executors tab.
  3. In the upper-right corner, click + Add. The Create pop-up is displayed.
  4. In the Create pop-up, do the following:
    FieldDescription
    NameEnter the name of the executor.
    UsernameEnter a username to access the executor.
    PasswordEnter a password to access the executor.
    Timezone (Optional)Select a timezone.
    Description (Optional)Enter a description for the executor.
    Executor Type

    Select the executor type.

    Note: Based on the selected Executor Type, additional fields appear that require your input.

    Connection URLEnter the database URL
    HostEnter the Internet Protocol (IP) address of the host server where the database is located.
    PortEnter the port number of the server where the database is accessible.
    DatabaseEnter the database type.
    SystemSelect the checkbox to integrate the executor into the system.

    Note: The Driver Class fields are auto-populated based on the details entered in Type, Host, Port, and Database fields.

  5. (Optional) To test the connection to the database, click the Edit icon and click Test Connection in the Edit pop-up.
    • If the executor is connected to the database, a success message is displayed.
    • If the executor is not connected to the database, an error message is displayed.
  6. Click Save. The executor is added and displayed in the ETL Executors tab. You can now add the executor in any of the workspaces available to you.

    Note: For more information about adding executors to a workspace, see Managing Workspace Executors.

Modifying an ETL Executor

To modify an ETL executor, do the following:

  1. Log in to Synergy.
  2. From the Admin drop-down, select Executors. All existing data executors are displayed in the ETL Executors tab.
  3. In the Actions column for the executor that you want to modify, click the Edit icon. The Edit pop-up is displayed.
  4. Make the necessary changes and click Save. A confirmation message is displayed.
  5. Click OK. The changes are saved.

Note: To delete an executor, in the Edit pop-up, click Delete.

Modifying a Code Executor

To modify a Code Executor, do the following:

  1. Log in to Synergy.
  2. From the Admin drop-down, select Executors. All existing data executors are displayed in the ETL Executors tab.
  3. Navigate to the Code Executors tab, and in the Actions column for the Code Executor that you want to modify, click the Edit icon. The Edit Code Executor pop-up is displayed.
  4. Make the necessary changes and click Save. A confirmation message is displayed.
  5. Click OK. The changes are saved.

Note: To delete a Code Executor, in the Action column, click the Delete icon.
