Adding a Cluster Layer

Cluster layers enable you to group nearby geo-points into clusters, allowing you to view the number and distribution of records in densely populated map areas.

To add a Cluster layer and analyze data on the map, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Mouse over Tools and select Map Explorer. The Map Explorer component is displayed.
  4. In the Layers tab, click + Add Layer and select Schema. The Layer settings section is displayed.

    Note: You can select Collections to create a schema using the records saved in a collection.

  5. In the Layer settings, do the following:
    1. From the Select schema drop-down, select the required schema. The tables in which the coordinates are available are displayed in the Source coordinates field.
    2. Enter a name for the layer, and from the Type drop-down, select Cluster.
    3. (Optional) To apply spatial filter to the selected schema, do the following:
      1. Click + Area and select the drawn areas or area folders.
      2. Enable Within or Outside to query inside or outside the selected area.
    4. Click Create layer. The cluster layer is created and displayed on the map.
  6. (Optional) To apply filter to the schema, do the following:
    1. Click the Add filter icon.
    2. From the Select field list, select a schema field. For example, select duration.
    3. From the Operators list, select an operator. For example, select >.
    4. In the Value field, enter value. For example, enter 300. The filter is applied to the Layer.

      Note: You can click the X icon to remove the filter.

  7. In the Layer settings, select a default color.

  8. In the Point coordinate field(s) section, select the field that contains the latitude and longitude values used to plot each record on the map.

  9. In the Label field, select the field to display as a label on the map.

  10. In the Size field, select a numeric field that determines the size of each point. For example, Duration.

  11. From color field, select a field to color-code the paths based on their values. For example, select From Phone to distinguish records by whether they originated from a phone.

    1. Click Configure color field icon.

    2. From the Select palette drop-down, select a color palette and click Save.

  12. From the Tooltip fields drop-down, do one of the following:

    • Click Add all to include all available fields to display in the tooltip.

    • From the drop-down, select specific fields you want to display in the tooltip.

  13. (Optional) From the Sorting list, select relevant field to control the result order. For example, select duration.

  14. (Optional) In the Result size, enter the number of records to display. For example, enter 100.

  15. Click the Search icon at the top of the Map Explorer pane. The Heatmap layer is rendered on the map based on the configured settings.
