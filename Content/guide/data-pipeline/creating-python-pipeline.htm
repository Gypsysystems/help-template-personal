Creating a Python Pipeline

A Python Pipeline enables you to enter Python code in a Python editor to transform data. You can apply custom logic and use machine learning models to enrich the transformation results. You can create and execute Python Pipelines as part of an ETL process or independently, allowing for flexible data processing and analysis.

To create a Python pipeline in a workspace, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. In the Navigation pane, click the Pipelines icon. The Pipelines component is displayed.
  4. In the Pipeline toolbar, click + New analytical pipeline. The Analytics Pipeline tab is displayed.
  5. To add a Python step, click New step and select Python. The new step and the New Step configuration pop-up are displayed on the canvas.
  6. In the pop-up, do the following:

    Field

    Description

    Description (Optional)Enter a description for the pipeline.
    Library listEnter the external libraries or packages required for executing the script or query.
    Split task to Enter the number of parallel execution units to split the task into for improved scalability and processing performance.
    ExecutorSelect the relevant executor that matches the query conditions and data type.
    Code Editor

    Enter your query or script you want to execute.

    Note: You can use the AI Assistant to create queries and scripts.

    Parameters (Optional)

    To set parameters to your query or script, in the toolbar, click the Parameters icon, enter the following parameters, and click Apply.

    Field

    Description

    Task timeoutEnter the maximum execution time allowed for the task before it automatically stops in milliseconds (ms).
    Query limitEnter the maximum number of records the query should return.
    Source limitEnter the amount of source data processed during execution to optimize performance and resource usage.
    Execution Priority

    Select one of the following execution priority level for the task:

    • Highest
    • High
    • Medium
    • Low
    • Lowest
    Validate ReferencesSelect this checkbox to verify that all referenced tables, columns, datasets, and objects exist before the execution begins.
    Validate ExecutorsSelect this checkbox to verify whether the required executors, workers, or compute resources are available and operational.
    Ignore DependenciesSelect this checkbox to allow the task to execute without waiting for dependent tasks or upstream processes to complete.
    OutputSelect a working directory to store the results and to use them in the subsequent steps.
    Truncate beforeEnable this option to clear the selected table before loading new data. If enabled, the system truncates the table and loads the new data.
    ConnectionsSelect the appropriate operators to define the sequence and flow of execution within the pipeline.
    Conditional execution

    To configure when the step should be executed, mouse over the incoming connection of that step. You can select one of the following:

    • Success: The selected step runs only when the upstream step completes successfully.

    • Fail: The selected step runs only when the upstream step fails.

    Success condition type

    Select a relevant success condition type to define the success condition for the step.

    • Step executed successfully: Indicates that the step is successful if the step executed successfully.
    • Step has results: Indicates that the step is successful if the step executed with results.
    • Step has no results: Indicates that the step is successful if the step has no results.
  7. To execute the query, In the toolbar, click Execute entire script. The Output tab displays the query executed, date and time of execution, number of rows returned, and the time taken to execute. It also displays any errors occurred during the execution.
  8. Close the pop-up and click Save. The New Analytics Pipeline pop-up is displayed.
  9. Enter the following details:

    Field

    Description

    NameA name for the pipeline.
    Tags (Optional)

    A name for the tag.

    Note: Tag helps members of the workspace to know the intent of this step.

    Folder (Optional)Saving location for the step.

Note: You can add multiple sequential steps to search for data, transform it, and include it in the output table.
