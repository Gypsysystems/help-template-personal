Working with Pipelines

This section details the features available in the Pipeline and the Analytics Pipeline components.

Scheduling a Pipeline Execution

You can schedule a pipeline execution, the frequency of the execution, and the overlap policy if there are any pipelines scheduled to be executed at the same time.

To schedule a pipeline execution, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click the pipeline which you want to schedule. The pipeline is displayed in a new tab.
  4. Click the Edit icon on the right. The Edit mode is enabled.
  5. In the Pipeline toolbar, click the Settings icon. The Pipeline Settings pop-up is displayed.
  6. Click the Schedule tab.
  7. On the Schedule tab, in the Cron expression field, click the three dots menu (...) and select the frequency after which the pipeline steps should be executed. The selected frequency is displayed as a Cron expression in the Cron expression field.

    Tip: Click Clear to clear any existing selections.

  8. In the Stop at field, select the date and time when you want the execution to be stopped.
  9. From the Overlap Policy drop-down, select the required Overlap Policy. The following overlap policies are available:

    Overlap Policy

    Description

    SkipSkips the execution of the pipeline steps.
    Buffer OneExecutes the step as soon as the current step is completed. This will buffer only one existing pipeline.
    Buffer AllExecutes the steps after all the scheduled pipelines are executed sequentially.
    Cancel OtherCancels the already running pipelines and then executes the current pipeline after the cancellation is completed.
    Allow AllExecutes all the pipelines simultaneously.
  10. (Optional) To stop executing the transformation steps when it fails, enable the Stop on failure toggle icon.
  11. (Optional) To pause the execution until further action, enable the Paused toggle icon.
  12. (Optional) To specify an invocation limit, enable the Invocation limit toggle icon and in the Max Invocations field, specify the invocation value.

    Info: An invocation limit refers to the maximum number of times a pipeline can be executed within the specified time.

  13. Click Save to save the scheduler.

Configuring Notifications

To receive notifications whenever a schedule pipeline is executed, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click the pipeline which you want to configure notifications. The pipeline is displayed in a new tab.
  4. Click the Edit icon on the right. The Edit mode is enabled.
  5. In the Pipeline toolbar, click the Settings icon. The Pipeline Settings pop-up is displayed.
  6. Click the Notifications tab.
  1. From the Notification Condition drop-down, do one of the following:
    • If you do not want to be notified, select Never.
    • If you want to be notified whenever a pipeline is executed, select Always.
    • To specify a condition for the notification based on step results, select Step results and do the following:
      1. From the Step condition drop-down, select the pipeline steps for which you want to be notified.
      2. From the Operator drop-down, select And or OR. This specifies whether you want to be notified when all selected steps are executed or when any step is executed.
  2. (Optional) In the Labels field, enter the text and select it to add it as a label. Labels are displayed in the Notification alert pop-ups and help in quickly identifying the notification.
  3. From the Severity drop-down, select one of the following severity levels based on the severity of the notification:
    • Normal
    • Medium
    • Critical
  4. From the Destination drop-down, select the destination from where you want to host the notification.

    Note: Destinations are interfaces that receive notifications from rules. Only the users with Administrator privileges can create Destinations.

  5. (Optional) In the Subject template field, enter a subject for the notification.
  6. (Optional) In the Message template field, enter a message for the notification.
  7. Click Save. The notification is saved and a confirmation message is displayed.

Viewing the Pipeline Execution Result

To view a pipelines execution result, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click the pipeline for which you want to view the pipeline execution results. The pipeline is displayed in a new tab. All the past executions for the selected pipeline are displayed in the All tab.
  4. Select the relevant execution. The results of the selected execution are displayed on the right.
    • If the pipeline is executed successfully, the results are updated in the output table. You can create a schema or update an existing one.
    • If the step fails, the system displays an error with the reason for the failure.

Manually Executing a Pipeline

To manually execute a data pipeline, do the following:

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Click the pipeline which you want to execute. The data pipeline is displayed in a new tab.
  4. In the Pipeline toolbar, click Run. The pipeline execution process starts and is displayed in the Execution tab.

    Tip: To stop an execution that is in progress, in the Execution tab for that pipeline, click Stop.

Using Variables in Pipelines

Variables enable you to parameterize pipeline configurations and reuse pipelines across different environments or execution contexts without modifying the pipeline logic. Synergy supports defining variables at both the workspace level and the pipeline level.

Variables can be referenced within pipeline steps, queries, and configurations during execution.

Defining Workspace-level Variables

Workspace‑level variables are shared across all pipelines within a workspace. These variables are typically used to store environment‑specific or common configuration values such as data source names, database names, or environment identifiers.

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. In the Workspace panel, click the Settings icon. The General tab is displayed in the Settings page.
  4. Click Variables. The workspace variables page is displayed.
  5. Enter the following details:
    • Variable key: Enter the name of the variable.
    • Variable value: Enter the value associated with the variable.
  6. Click + Add variable. The variable is added to the Variables page.

Defining Pipeline-level Variables

Pipeline‑level variables are specific to a single pipeline. These variables are useful when a value is relevant only to a particular pipeline and should not be shared across the workspace.

  1. Log in to Synergy.
  2. From the Open Workspace drop-down, select the relevant workspace. All available workspace components are displayed.
  3. Open the required pipeline.
  4. On the pipeline toolbar, click Settings. The Pipeline settings pop‑up is displayed.
  5. Click the Variables tab.
  6. Enter the following details:
    • Variable key: Enter the name of the variable.
    • Variable value: Enter the value associated with the variable.
  7. Click Add variable to include the variable.
  8. Click Save to apply the changes.
