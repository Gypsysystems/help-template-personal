Exploring the Data Explorer UI

The following image illustrates the Data Explorer UI elements:

This image is for illustrative purposes only and does not represent real data. 

The following table explains the elements available in the Data Explorer UI:

#

Element

Description
Data Explorer

Enables you to select a schema based on which you want to find the data.

You can also refine your search by:

  • Adding filters.
  • Selecting Profiles or Profile Sets.
  • Sort data based on columns.
  • Indicate the maximum number of records you want to view.
  • View data in Grid, Map, or on Timeline.
  • Group data by specific column name.
  • Add multiple Metrics to analyze the search result data.
  • Create a snapshot of the search result.
Data View

Displays data in the selected Grid format, any specific chart, timeline, or Map.
