Working with Data Sources

This section details the common features available across all data source types.

In this Topic
  • Creating a Data Source
  • Viewing a Data Source and its Elements
  • Deleting a Data Source Element
  • Syncing a Data Source or its Elements
  • Modifying Data Source Details

Creating a Data Source

To create a data source, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. In the Data Management pane, click the New Datasource icon. The Create new datasource pop-up is displayed.
  4. Enter the following details:

    Field

    Description

    NameEnter a unique name for the data source.
    Type Select the data source type or the storage system to connect.
    Driver Class Auto-generated based on the selected data source type; defines the driver used to connect.
    URLAuto-generated connection URL based on the selected data source type.
    HostEnter the server address where the data source is hosted.
    PortSpecify the port number used to connect to the database.
    DatabaseProvide a name for the database.
    Access PermissionSelect the level of access for the data source. The available options are Read and Write.
    UsernameEnter a username for authenticating the data source.
    PasswordEnter a password for authenticating the data source.
    TimezoneSelect the timezone in which the database operates.
    Test ConnectionClick to verify the connection to the database.
  5. Click Save. The data source is saved and is displayed in the Data Management pane.

Viewing a Data Source and its Elements

The Data Management component displays all the data sources associated with a workspace in a hierarchical layout.

To view a data source and its elements, such as folders, schemas, data tables, and so on, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Click a data source or its elements to expand and view them.

You can view, add, and modify the details of database tables and folders, depending on the type of data source.

Deleting a Data Source Element

To delete a data source element, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Click the data source in which you want to delete a data source element and navigate to that element.
  4. Right-click the data source element that you want to delete and click Delete. A confirmation message is displayed.
  5. Click OK to confirm. The selected data source element is deleted from the workspace.

Syncing a Data Source or its Elements

To sync a data source or its elements with the workspace, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Click the data source that you want to sync with the workspace.

    Tip: You can navigate to a data source element to sync it with the workspace.

  4. Right-click the data source element which you want to sync and click Sync. The data source and its elements are synced with the workspace.

Modifying Data Source Details

To modify the details of a data source, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Right-click the data source you want to modify and click Details. The details of the data source are displayed.
  4. Make necessary changes and click Save. The changes are saved.

Note: To delete a data source, in the Edit datasource section, click Delete.
