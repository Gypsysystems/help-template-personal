Working with a Minio and an S3 Data Source

This section explains the features available for Minio and S3 Data Sources

In this Topic
  • Creating a Bucket
  • Creating a Folder
  • Uploading a File
  • Viewing the Database Folder Details
  • Viewing the Database File Details

Creating a Bucket

To create a bucket in a Minio or an S3 data source, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Right-click a Minio or an S3 data source in which you want to create a bucket and click Create bucket. The Create Bucket pop-up is displayed.
  4. Do the following:
    1. In the Name field, enter a name for the bucket.
    2. (Optional) In the Description field, enter a description for the bucket.
  5. Click Save. A new bucket is created and displayed in the selected Minio or S3 data source.

You can now create folders within a bucket.

Creating a Folder

You can organize database files by creating folders in a bucket or folders within a folder.

To create a folder in a bucket, do the following:

  1. In the Data Management component of a workspace, click a Minio or an S3 data source to expand it. All available buckets in that data source are displayed.
  1. Right-click the bucket in which you want to create a folder and select Create folder. The Create Folder pop-up is displayed.
  2. Do the following:
    1. In the Name field, enter a name for the folder.
    2. (Optional) In the Description field, enter a description for the folder.
  3. Click Save. A new folder is created and displayed in the selected bucket.

    Tip: Similarly, you can create a folder within a folder that is in a bucket.

Uploading a File

To upload a database file into a folder, do the following:

  1. In the Data Management component of a workspace, click the chevron icon beside a Minio or an S3 data source to expand it. All available buckets in that data source are displayed.
  2. Click the relevant bucket to expand it. All available folders in that bucket are displayed.
  3. Right-click the folder to which you want to upload a file and select Upload file. The Create File pop-up is displayed.
  4. Do one of the following:
    1. Click within the Create File pop-up. The standard Open pop-up is displayed.
    2. Browse and select the file that you want to upload from your local computer and click Open. The file name and the upload progress bar are displayed in the Create File pop-up.
    3. Click Upload. The file is uploaded into the selected folder.

    Tip: Alternatively, you can drag and drop a file inside the Create File pop-up and then click Upload.

Viewing the Database Folder Details

To view the details of a database folder, do the following:

  1. In the Data Management component of a workspace, click a Minio or an S3 data source to expand it. All available folders in that data source are displayed.
  2. Mouse-over the relevant database folder and click details. All the folder details are displayed in the Item Details pop-up.

Viewing the Database File Details

To view the details of a database file, do the following:

  1. In the Data Management component of a workspace, click a Minio or an S3 data source to expand it. All available folders in that data source are displayed.

  2. Click the relevant folder to expand it. All available files in that folder are displayed.

  3. Right-click the relevant file and click Open details. The Details pop-up is displayed. The following table explains the tables available in the Details pop-up:

    Tab

    Description

    Columns

    Displays all columns available in the table, including column names, data types, and size.

    Preview

    Provides a preview of the data stored in the table in an SQL editor, allowing you to quickly inspect rows and column values.

    You can do the following in the Preview tab:

    • Run a selected query or the entire script.
    • Add parameters such as Task timeout, Query limit, Source limit, and so on.
    • Select an executor to execute the query.
    • Open and use AI Assistant to modify the query.
    Query LogDisplays the history of executed queries related to the table or database. You can use the available filters and search options to find specific queries.
    Lineage

    Displays the data lineage and relationships between tables. It helps in tracking where the data originates and how it flows across the system.

    To view a table's details, in the Lineage tab select the relevant data table. All the details of the selected table are displayed in the right pane.
