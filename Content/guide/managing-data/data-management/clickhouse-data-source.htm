Working with a ClickHouse Data Source

This section explains the features available for a ClickHouse Data Source.

In this Topic
  • Creating a Schema
  • Creating a Database Table
  • Adding a Database Table to a Data Catalog
  • Viewing the Database Table Details

Creating a Schema

To create a schema in a ClickHouse data source, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Right-click the data source from which you want to create a schema and click Create Schema. The Create data base schema or catalog pop-up is displayed.
  4. Enter a name and a description for the schema and click Save. The schema is created and displayed in the selected data source.

You can now create the database tables within that schema.

Creating a Database Table

To create a database table in a ClickHouse data source, do the following:

  1. Log in to Synergy.
  2. In the top navigation bar, from the Management drop-down, select Data Management. All available data sources are displayed on the Data Management page. The schemas, tables, folders, and columns are displayed in a hierarchical layout within each data source.
  3. Expand a relevant table, right-click the schema in which you want to create a table, and click Create Table. A pop-up explaining the process to add a table is displayed.
  4. Select the schema in which you want to create the table.
  5. You can create a table in the following ways:
    • To create a table using AI Assistant, select Describe with human language and describe the table you want to create in natural language.
    • To create a table by uploading a CSV file, select From CSV and upload the relevant .csv file.
    • To create from DDL, select From DDL and paste the DDL statement.
    • To create from existing table/file, select From existing table/file and select the table or the file from the drop-down.
    • To manually enter the columns, select Manually enter all the columns.
  6. Click Next, and in the Advanced Settings section, add or modify the table columns.
  7. Click Next and verify and configure the Storage and TTL.
  8. Click Finish. The table is created and displayed in the selected schema.

Adding a Database Table to a Data Catalog

You can organize schemas in the data catalog component by adding data tables to an existing data catalog.

To add a database table to a data catalog, do the following:

  1. In the Data Management component of a workspace, click a ClickHouse data source to expand it. All available schemas in that data source are displayed.
  2. Click a schema from which you want to add a data table to an existing data catalog.
  1. Right-click the relevant table and select Add to Data Catalog. The Create Analytics Schema pop-up is displayed.
  2. From the Catalog drop-down, select a relevant data catalog to which you want to add the selected database table.
  3. (Optional) If required, make changes to the parameters of the columns in the database table.
  4. Click Save. The database table is added to the selected data catalog. The newly added database table is displayed in the Data Catalog component.

    Tip: To delete a database table, in the Create Analytics Schema pop-up, click Delete.

Viewing the Database Table Details

To view the details of a database table, do the following:

  1. In the Data Management component of a workspace, click a ClickHouse data source to expand it. All available schemas in that data source are displayed.
  2. Expand the relevant schema. The available database tables are displayed.
  3. Right-click the relevant database table and click Open details. The Details pop-up is displayed. The following table explains the tables available in the Details pop-up:

    Tab

    Description

    Columns

    Displays all columns available in the table, including column names, data types, and size.

    To add a column to the table, do the following:

    1. On the Columns tab, click + Add Column. The Edit column pop-up is displayed.
    2. In the Name field, enter a name for the column.
    3. (Optional) From the Type drop-down, select the data type.
    4. (Optional) If the data is nullable, click the Nullable toggle icon.
    5. (Optional) In the Description field, enter a description for the column.
    6. Click Add. The new column is added to the database table.
    Lineage

    Displays the data lineage and relationships between tables. It helps in tracking where the data originates and how it flows across the system.

    To view a table's details, in the Lineage tab select the relevant data table. All the details of the selected table are displayed in the right pane.

    IndexesDisplays indexes configured for the table.
    ProjectionsShows configured projections or query structures that optimize analytical queries and improve performance for large datasets.
    TTLDisplays Time-to-Live (TTL) configurations that automatically manage data expiration, retention, or deletion policies.
    PartitionsShows how the table data is partitioned or segmented for efficient storage and faster query execution.
    Query LogDisplays the history of queries executed on the table or database.
    Statistics (ClickHouse table statistics)Displays table-level statistics, such as row count, storage size, compressed and uncompressed data size, number of parts, and other metadata. These statistics help you analyze table usage, monitor storage consumption, and optimize query performance.
    Lock HistoryDisplays the lock activity recorded for the table, including status, query, start time, and end time. Use this tab to review table access conflicts, identify blocked operations, and troubleshoot issues caused by concurrent database activities.
    BackupsDisplays the backup history available for the table, including backup name, origin, partition, pipeline, size, and save mode. Use this tab to verify whether the table has valid backups and to track backup operations for recovery or audit purposes.
    Preview

    Provides a preview of the data stored in the table in an SQL editor, allowing you to quickly inspect rows and column values.

    You can do the following in the Preview tab:

    • Run a selected query or the entire script.
    • Add parameters such as Task timeout, Query limit, Source limit, and so on.
    • Select an executor to execute the query.
    • Open and use AI Assistant to modify the query.
    DDLDisplays the Data Definition Language (DDL) script used to create the table, including schema definitions, engine settings, indexes, partitions, and other configurations.
